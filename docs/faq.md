# 常见问题

这份文档优先回答玩家会直接问出来的问题。

## 打开后是空白页

先按这个顺序检查：

1. 重新打开一次程序
2. 确认你打开的是新的 `d2-tools.exe`
3. 如果是覆盖安装后的版本，确认安装流程已完成
4. 如果仍然空白，优先保留 `%APPDATA%\d2-tools`，不要急着删数据目录

如果是测试包问题，反馈时最好说明：

- 你打开的是哪个版本
- 是安装后的程序，还是开发构建里的 `win-unpacked` 程序
- 空白前有没有看到引导或登录页

## 为什么登录不了 Bungie

最常见原因有 4 个：

1. 你没有使用自己的 Bungie Application
2. `API Key`、`Client ID`、`Client Secret` 填错了
3. 回调地址不是 `https://127.0.0.1:28780/oauth/callback`
4. 本地回调被系统或安全软件拦截

先看 [Bungie 配置指南](bungie-setup.md) 对着核一遍。

## 为什么授权后软件还是没登录

通常先排查：

- d2-tools 是否还在运行
- 回调地址和程序实际端口是否一致
- 本地浏览器回跳是否成功打开了 `127.0.0.1` 回调页

如果回调页开了，但软件没更新状态，通常不是 Bungie 账号问题，而是本地回调链路没接住。

## 为什么资料库搜不到装备

先确认两件事：

1. Bungie 配置已经保存
2. 资料库没有处于“需修复”状态

然后再试：

- 换中文名
- 换英文名
- 用部分名称搜索
- 如果是 perk，切到 perk 搜索模式

如果本地资料库本身没有某个条目的中文名称或关联信息，d2-tools 会明确显示缺字段，不会猜。

如果资料库后台准备失败，回到设置页 Bungie 区域，点击“重试准备资料库”；配置本身不需要重新填写，已登录账号也不需要重新授权。

## 为什么 AI 不能用

AI 助手页只会在配置完整时正常工作。

你需要检查：

- 是否在设置页选择了 AI API 格式
- 是否填了 API Key
- 是否填了模型名
- `base_url` 是否正确；根地址和完整接口地址都可以，但要和当前 API 格式匹配

支持的方式包括：

- OpenAI Responses
- OpenAI Chat Completions
- Anthropic Messages

未配置时，AI 页会提示你跳去设置页。

## 为什么写操作按钮是灰的或操作被拒绝

应用没有额外的本地写操作总开关。写操作是否可执行取决于当前账号授权、操作目标和运行状态。

你需要同时满足：

1. Bungie 授权具备对应 Scope
2. 当前操作具备实例、目标角色等可执行条件
3. 当前没有同类写操作正在执行

写操作包括：

- 锁定 / 解锁
- 装备
- 仓库转移
- 一键装备最高光等

## 为什么游戏里看不到我在 d2-tools 里做的本地标记

因为这些标签和备注是 d2-tools 本地数据，不是 Bungie 游戏内原生标签。

也就是说：

- 你可以在 d2-tools 里标“保留 / 待定 / 清理”
- 这些标记不会同步成游戏里可见的官方 UI 标记

所以清理时最好用 d2-tools 提供的定位信息、光等、锁定状态和 perk 去核对。

## 为什么 d2-tools 不能直接分解装备

这是故意的产品边界，不是功能缺一半。

原因很简单：

- 分解是高风险、不可逆操作
- 一旦误操作，玩家损失很大

所以 d2-tools 只帮你做：

- 标记
- 解锁
- 转移
- 定位

最终分解仍然需要你进游戏手动完成。

## 覆盖更新会不会丢历史记录

正常覆盖程序目录时，不会删掉 `%APPDATA%\d2-tools` 里的数据。

通常能保留下来的包括：

- Bungie 配置
- token
- 资料库缓存
- 仓库标签
- 备注
- 愿望单导入
- 操作日志

真正容易丢的是你自己手动删除了数据目录。

## 今日 / 本周为什么有些内容是空的

这是正常现象，不一定代表功能坏了。

d2-tools 的原则是：

- 只展示 Bungie API 或本地资料库能确认的内容
- 不能确认的内容明确显示为空、未接入或无数据
- 不靠猜测补齐

## 我可以把它当多人共享服务用吗

当前主入口不是中心化服务，而是本地 Windows 客户端。

你当然可以自己研究 HTTP / 工具接口方向，但对普通玩家来说，推荐的使用方式仍然是：

- 每个人自己配置 Bungie Application
- 每个人自己在本机使用

## 我还想确认 AI 会不会保存我的装备信息

本地配置、标签、备注和日志会保存在你的电脑里。

至于 AI：

- d2-tools 会把你当前提问所需的结构化账号数据发给你选择的模型提供方
- 但不会把 token、Client Secret 或 API Key 发过去

更完整的边界说明见 [安全说明](security.md)。
