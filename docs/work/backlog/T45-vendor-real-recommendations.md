# T45：商人真实推荐（已取消）

> 状态：⛔ 已取消
> 优先级：P0
> 取消原因：游戏内商人界面已经展示本次售卖的实际 Perk / Roll；应用再做一层“显示商人 Roll”或把异域品质包装成推荐，增量价值不足且容易造成误导。

## 结论

商人售卖武器不是“每次购买时由本应用重新随机生成 Roll”。Bungie 返回的是当前刷新周期的 Offer 及其可见配置；部分商人或购买方式可能存在随机池，但只有 API 明确返回实际配置时才可判断，不能凭武器身份推测玩家最终会获得什么。

因此本需求不再建立商人专用推荐算法、推荐筛选或推荐 Worker 接入。未来如果出现明确的跨账号决策需求，应作为新的未占用任务单独立项，不复用 T45 编号。

## 保留到其他需求的内容

- 账号是否已有同身份装备、收藏是否解锁：见 T46。
- 刷新后 Offer 新增、下架和购买条件变化：见 T47。
- 商人护甲对当前构筑的影响：见 T48。
- 玩家关注特定物品或条件并在刷新后提醒：见 T49。
