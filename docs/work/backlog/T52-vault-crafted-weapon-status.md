# T52：仓库武器区分锻造与强化状态

> 状态：🟠 代码完成，待真实账号验收
> 优先级：P1
> 类型：仓库实例状态展示

## 目标

让玩家在仓库武器网格中直接识别普通、锻造和强化武器，不需要逐件打开详情，也不把强化掉落武器误标为锻造武器。

## 数据与展示边界

- 使用 Bungie `DestinyProfileItem.state` 的 `Crafted` 状态位识别锻造体系实例。
- 状态位存在且武器定义有 `inventory.recipeItemHash` 时显示“锻造”；没有制作配方时显示“强化”。
- 使用 `DestinyInventoryItemConstantsDefinition` 的官方锻造背景、锻造覆盖图和强化覆盖图，不用名称或 CSS 图案猜测。
- 卡片底部状态行同时显示“锻造 / 强化”文字；普通武器不占位。
- 不新增筛选、排序、同步请求或推荐权重，不改变固定卡片高度。

## 验收

- 同步装备数据后，实际锻造武器显示官方锻造图层和“锻造”。
- 可强化的随机掉落实例显示官方强化图层和“强化”，不显示“锻造”。
- 普通武器没有制作状态标记。
- 锻造图层、强化图层和装备阶级覆盖图同时存在时均可辨认。
- 紧凑、默认和舒适密度下卡片高度不变化，滚动与取出后的焦点保持稳定。
