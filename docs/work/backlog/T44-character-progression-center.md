# T44：角色进度中心

> 状态：📝 候选方案，待排期
> 优先级：P2
> 类型：独立异步进度资源
> 所属需求组：[T24 账号菜单角色准备与风险中心](T24-account-readiness-risk-center.md)

## 1. 目标

在不拖慢账号装备首屏的前提下，展示当前角色仍值得完成的强力与巅峰奖励，以及赛季等级和主要声望进度。

## 2. 范围

- 当前角色强力和巅峰奖励完成状态。
- 奖励相对当前掉落基准的潜在提升价值。
- 赛季等级、下一奖励和距离升级的进度。
- 主要声望等级、下一奖励和重置次数。
- 三角色概览增加本周高价值奖励状态。

首页继续回答“本周有哪些活动”，账号菜单只回答“当前角色哪些奖励已经完成、还差多少、是否仍值得做”。

## 3. 数据架构约束

- 根据实际字段评估 `CharacterProgressions`、`CharacterActivities`、`ProfileProgression`、Milestones 或其他必要组件。
- 进度数据设计为独立异步资源，不加入装备首屏的阻塞请求。
- 进度资源拥有独立缓存、过期时间、in-flight 复用和失败状态。
- 不得为了一个进度分区让每次账号装备同步都重新拉取完整 Progress 数据。
- 进度请求失败时继续保留角色装备、容量、邮政官和光等能力。
- 首页与账号菜单共享同一标准化进度 DTO，不分别解析 Bungie 原始响应。

## 4. 非目标

- 不复制 DIM 的完整 Progress 页面。
- 不在账号菜单实现全部成就、收藏、活动卡和 Pathfinder 树。
- 不把活动攻略和推荐配装塞入进度面板。
- 不用活动名称、奖励图标或固定周期猜测完成状态。

## 5. 验收标准

- 强力和巅峰奖励状态与当前角色游戏内进度一致。
- 玩家能区分已完成、可继续推进、不可用和数据过期状态。
- 奖励价值建立在真实掉落基准上，不使用固定“值得做”标签。
- 赛季和声望请求不会延长账号装备首屏的可用时间。
- 首页与账号菜单对同一活动和完成状态的描述一致。
- 部分进度数据失败时只影响对应模块，不导致整个账号菜单加载失败。
