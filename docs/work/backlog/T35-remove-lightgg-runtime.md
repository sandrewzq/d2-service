# T35：移除 light.gg 专用实时分析

## 目标

从应用运行时中删除 light.gg 专用实时分析，避免把无法稳定访问、没有正式接口契约的网页读取包装成可靠推荐来源。

## 已实施范围

- 删除 light.gg 专用 AI Source、解析器、缓存、后台任务、IPC/API 契约和装备详情来源展示。
- 删除设置页中的 light.gg 启用与强制启用开关。
- 保留单件装备的通用 AI 外部知识查询；只有用户主动允许时调用，并要求使用支持网页引用的 OpenAI Responses 兼容接口。
- 保留 DIM Wishlist、本地中文推荐、个人知识和其他既有推荐来源。
- 配置格式升级到版本 2；旧 `enable_lightgg`、`force_lightgg` 字段在升级或备份恢复时自动剥离。
- 配置升级时尽力清理旧 `cache/lightgg` 目录，清理失败不阻止应用启动。
- `destiny-tool-reference.md` 中的 light.gg 仅作为普通外部工具导航保留，不代表应用运行时依赖或集成。

## 验收标准

- 设置页不再出现 light.gg 开关或支持状态。
- 仓库与装备详情不再出现 `AI · light.gg` 来源、降级提示或缓存清理项。
- 旧版本配置和便携备份可以正常导入，并持久化为不包含旧字段的新配置。
- 单件装备仍可选择通用 AI 外部知识查询；未主动允许时不访问外部网页。
- DIM Wishlist、本地推荐和人工来源的读取、匹配与失败降级逻辑保持不变。
