# T51：发布许可证与 AI 隐私边界

> 状态：🟡 代码完成，待验收

## 目标

- Windows 安装包展示 MIT License，并携带桌面运行时第三方许可证清单。
- 设置页可以直接打开项目许可证和第三方许可证清单。
- AI 首次发送游戏数据前常驻告知范围并要求玩家明确确认。
- AI 提示仅携带完成分析所需的数据摘要，不发送凭据、账号名或 Bungie 实体标识。

## 实现边界

- `licenses:generate` 从桌面运行时和 Renderer 打包依赖生成许可证清单，`licenses:check` 进入质量门禁。
- 旧 AI 配置迁移后默认未确认；便携备份不携带有效确认。
- 更换 API 格式或 Base URL 后撤销确认；选择“不启用 AI”可以直接保存。
- 模型列表和底层连接测试不发送游戏上下文；模型列表可在确认前使用，“保存并测试连接”仍受保存确认约束。
- AI 对话、仓库建议、单件装备分析和外部知识查询在后端统一检查确认状态。

## 验收

- 安装向导显示项目许可证，安装后设置页两个许可证按钮均能打开对应文件。
- 从旧版本升级后，已配置 AI 显示“待确认”，未确认时 AI 请求被阻止。
- 勾选确认并保存后，AI 对话和分析恢复可用。
- 更换 API 格式或 Base URL 后确认自动取消，必须重新勾选。
- 设置为“不启用 AI”时无需勾选即可保存。
- 便携备份恢复后必须在新电脑重新确认。
