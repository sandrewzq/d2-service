## 1. 产品结论

- 技术上可以实现，基础开发难度不高，但稳定发布依赖官方授权和稳定接口。
- 该能力属于实用增强，不是应用核心功能，不应绕过授权抢先上线。
- 未经授权直接调用官网内部 Astro Action 存在中高风险，当前不得进入正式开发或 Release。
- 官方不授权或长期无回复时，只提供 D2Checkpoint 官网导航和中文使用说明，不读取实时状态。

## 3. 已发送的授权申请

用户已于 2026-09-08 向 `support@d2checkpoint.com` 发送邮件，等待官方书面回复。申请确认以下事项：

- 是否允许公开发布的桌面应用展示实时机器人状态。
- 是否存在正式、稳定的 API。
- 官方推荐客户端直连，还是由项目服务端中转缓存。
- 允许的刷新频率、限流和缓存规则。
- 数据来源署名、官网链接和 Logo 使用要求。
- 是否允许将连接、保存进度和行为规范翻译为中文。
- 开源和公开发布是否存在其他附加条件。

无回复不得默认视为授权。授权证据应保存为可追溯的邮件或官方消息记录，但不得把私人邮件地址、令牌或无关个人信息提交到仓库。

## 4. 获得授权后的候选架构

具体接口和频率以官方回复为准，当前只冻结边界，不提前锁定内部 Action：

```text
D2Checkpoint 官方允许的数据源
              ↓
Desktop 主进程 adapter
              ↓
5 分钟或官方指定周期缓存
              ↓
标准化 DTO
              ↓
packages/ui 共享页面
```

- 第三方请求由 Desktop 主进程负责，Renderer 不直接访问外部接口。
- 接口返回值先转换为本项目 DTO，UI 不依赖第三方原始字段。
- 活动名称优先通过本项目 Destiny 资料库映射。
- Manifest 缺失的遭遇战名称使用受控补充数据，不根据顺序或英文文本猜测。
- 如果官方要求统一中转，应单独评估服务成本、隐私、稳定性和限流，不自动扩大当前本地应用范围。
- 若获准使用内部 Action，应保留数据源熔断开关，以便官方变更或撤回授权后立即停用。

## 5. 功能范围

### 5.1 计划实现

- 只展示当前可用的 D2Checkpoint 进度机器人。
- 展示活动、遭遇战、难度、机器人名称和可用状态。
- 提供一键复制 `/join`；中文客户端按实际需要提供 `/加入`。
- 明确显示数据来自 D2Checkpoint，并提供可点击的完整官网地址。
- 展示官方连接流程、保存进度方式和封禁警告。
- 请求失败时保留最后一次成功缓存，并明确显示缓存时间；同时提供打开官网的降级入口。
- 页面继续由 `packages/ui` 共享，Web 和 Desktop 不维护两套实现。
- 明暗主题、状态语义、按钮层级和错误恢复遵循现有 UI 合同。

### 5.2 官方使用流程

产品内说明必须保持简洁但完整：

1. 如果角色已有更后面的进度，先重置对应活动进度。
2. 在轨道中复制并使用 `/join` 或中文客户端对应的 `/加入` 指令。
3. 进入后启动遭遇战并团灭一次。
4. 复活并确认进度后立即离开火力战队。
5. 禁止击杀 Boss、长期占用机器人或阻止正常团灭流程。

### 5.3 非目标

- 不自建或托管 Destiny 2 检查点机器人。
- 不做 Twitch 或其他排队系统自动化。
- 不控制键鼠，不自动输入游戏，不自动加入火力战队。
- 不抓取 D2Checkpoint 官网 DOM。
- 不使用已废弃的 `d2cp.io` 接口。
- 未获授权时不调用官网内部 Action。
- 未经明确许可不使用 D2Checkpoint Logo。

## 6. 授权回复决策矩阵

| 官方回复 | 后续处理 |
|---|---|
| 明确允许并提供正式 API | 按官方文档进入设计与开发 |
| 允许使用官网内部 Action | 严格遵守指定频率、缓存和署名要求，并保留快速熔断开关 |
| 只允许链接官网 | 只做官网导航和中文使用说明，不读取实时数据 |
| 明确拒绝 | 取消实时集成，保留是否需要官网导航的产品评估 |
| 长期无回复 | 保持暂停，不把沉默视为授权；最多实施纯导航方案 |

## 7. 验收标准

- 已取得并保存可追溯的官方书面授权证据。
- 只使用官方允许的数据源、请求频率、缓存方式和展示字段。
- 实时状态来自真实数据，不使用静态假数据伪装可用状态。
- 数据失败或过期时明确显示最后更新时间，并可降级打开官网。
- 活动、遭遇战、难度、机器人名称和可用状态映射准确。
- 复制的加入指令符合玩家当前游戏语言或提供清晰选择。
- 页面清楚展示官方来源、官网链接、使用规则和必要警告。
- 应用不自动操作游戏或 D2Checkpoint 机器人。
- Web 与 Desktop 继续消费 `packages/ui` 的同一共享页面。
- 明暗主题和现有 UI 合同一致。
