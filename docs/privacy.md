# 隐私说明

这份文档说明 d2-tools 会在本机保存什么、会向哪些外部服务发送什么，以及玩家如何停用相关能力。

## 1. 本地保存的数据

d2-tools 是本地运行的桌面工具。配置、Bungie OAuth token、Manifest 与账号缓存、仓库标签、备注、应用配装、操作日志和 AI 配置默认保存在当前电脑的数据目录中。

Windows 默认目录为：

```text
%APPDATA%\d2-tools
```

这些本地数据不会上传到 d2-tools 自建服务器。设置页可以打开实际数据目录；删除目录前应先完全退出应用并自行备份需要保留的内容。

## 2. Bungie 数据访问

玩家使用自己创建的 Bungie Application 完成授权。应用会从本机直接访问 Bungie API，以读取账号、角色、装备、仓库、活动、商人和其他已授权数据；写操作还需要对应 Bungie Scope 和玩家确认。

d2-tools 不提供 Bungie 账号中转服务，也不会把 Bungie OAuth token、Client Secret 或 Bungie API Key 发送给 AI 服务。

## 3. AI 数据发送

AI 是可选能力。只有玩家在设置页启用 AI、阅读数据发送说明并明确勾选同意后，AI 分析才会发送游戏数据。

请求会从本机直接发送到玩家所选 API 格式与 Base URL 对应的 AI 服务，不经过 d2-tools 自建服务器。根据实际问题，可能发送：

- 玩家输入的问题和当前页面上下文
- 装备名称、类型、位置、Perk、光等和锁定状态
- 仓库、角色装备、材料、配装、商人和活动的必要摘要
- 玩家主动写入的本地标签、备注、攻略文本或 AI 知识补充

应用会尽量只发送完成当前分析所需的摘要，不发送完整本地数据库。

## 4. AI 不会放入模型提示的数据

d2-tools 不会把以下内容放进问题、游戏上下文或模型提示正文：

- Bungie OAuth token
- Bungie Client Secret
- Bungie API Key
- AI API Key
- Bungie 账号名
- Membership ID 或 Membership Type
- 角色 ID
- 装备实例 ID
- 物品 Hash 或 Plug Hash

AI API Key 必须作为认证请求头发送到玩家配置的 AI 服务，否则该服务无法验证请求；它不会进入模型提示正文。Bungie OAuth token、Client Secret 和 Bungie API Key 不会发送到 AI 服务。

玩家主动在问题、备注或攻略正文中输入的内容会作为其主动提供的文本发送；应用无法替玩家判断自由文本中是否包含个人信息，因此发送前仍应自行检查。

## 5. 首次确认与重新确认

- 旧版本 AI 配置升级后默认为未确认，必须在设置页重新确认。
- 更换 API 格式或 Base URL 后，设置页会撤销原确认并要求重新确认。
- 便携备份不会携带有效的数据发送确认，恢复后必须在新电脑重新确认。
- 未确认时，模型列表仍可用于核对接口；连接测试本身只发送固定测试文本、不携带游戏上下文，但设置页的“保存并测试连接”仍需先完成保存所要求的确认。装备分析、仓库建议和 AI 对话不会发送游戏数据。

## 6. AI 提供方与外部搜索

玩家自行选择并配置 AI 提供方。发送后的数据处理、保留期限和训练策略由该提供方及 Base URL 实际运营方的隐私条款决定，d2-tools 无法代替第三方作出承诺。

单件装备的外部知识查询只有在玩家主动允许时才会执行，并会把搜索问题发送到当前 AI 服务。返回内容可能来自外部网页，应用会尽量保留可追溯链接，但第三方网页仍受各自条款约束。

## 7. 停用 AI

在“设置 → AI 助手”中把 API 格式改为“不启用 AI”并保存，即可停用 AI 数据发送。玩家也可以清空 AI Key，或在完全退出应用后从本地配置中删除 AI 配置。

安全凭据、本地备份和诊断导出的更多边界见 [安全说明](security.md)。
